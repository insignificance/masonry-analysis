3. remakeConstraints 流程

flowchart TD A["调用remakeConstraints"] --> B["创建ConstraintMaker"] B --> C["设置removeExisting = YES"] C --> D["执行用户Block"] D --> E["收集新约束"] E --> F["安装前清理"] F --> G["查找视图所有旧约束"] G --> H["逐个uninstall"] H --> I["清空旧约束"] I --> J["安装新约束"] J --> K["生成NSLayoutConstraint"] K --> L["添加到视图"] L --> M["返回新约束数组"]

关键代码：

// View+MASAdditions.m
- (NSArray *)mas_remakeConstraints:(void(^)(MASConstraintMaker *))block {
    self.translatesAutoresizingMaskIntoConstraints = NO;
    MASConstraintMaker *constraintMaker = [[MASConstraintMaker alloc] initWithView:self];
    constraintMaker.removeExisting = YES;  // 关键标志
    block(constraintMaker);
    return [constraintMaker install];
}

// MASConstraintMaker.m
- (NSArray *)install {
    // 1. 清理旧约束
    if (self.removeExisting) {
        NSArray *installedConstraints = [MASViewConstraint installedConstraintsForView:self.view];
        for (MASConstraint *constraint in installedConstraints) {
            [constraint uninstall];  // 逐个卸载
        }
    }

    // 2. 安装新约束
    NSArray *constraints = self.constraints.copy;
    for (MASConstraint *constraint in constraints) {
        constraint.updateExisting = self.updateExisting;
        [constraint install];
    }

    [self.constraints removeAllObjects];
    return constraints;
}

- (MASConstraint * (^)(id))equalTo {
    return ^id(id attribute) {
        // 处理不同类型
        if ([attribute isKindOfClass:MASViewAttribute.class]) {
            _secondViewAttribute = attribute;
        } else if ([attribute isKindOfClass:MAS_VIEW.class]) {
            // 自动转换为对应属性
            MAS_VIEW *view = (MAS_VIEW *)attribute;
            if (_firstViewAttribute.isSizeAttribute) {
                _secondViewAttribute = [[MASViewAttribute alloc]
                                       initWithView:view
                                       item:nil
                                       layoutAttribute:NSLayoutAttributeNotAnAttribute];
            } else {
                _secondViewAttribute = [[MASViewAttribute alloc]
                                       initWithView:view
                                       layoutAttribute:_firstViewAttribute.layoutAttribute];
            }
        }
        return self;  // 关键：返回self继续链式
    };

🔧 约束安装阶段详解

单约束安装 (MASViewConstraint)

flowchart TD A["install调用"] --> B{updateExisting?} B -->|是| C["查找已存在约束"] B -->|否| D["直接创建"] C --> E{"找到匹配?"} E -->|是| F["更新常量"] E -->|否| D D --> G["创建NSLayoutConstraint"] G --> H["找到安装视图"] H --> I["添加约束"] I --> J["完成"] F --> J

详细流程：

// MASViewConstraint.m
- (void)install {
    // 1. 处理更新模式
    if (self.updateExisting) {
        NSArray *installed = [MASViewConstraint installedConstraintsForView:self.firstViewAttribute.view];
        for (MASViewConstraint *constraint in installed) {
            if ([constraint isEqualToConstraint:self]) {
                // 找到匹配，更新而非创建
                [constraint setLayoutConstraint:self.layoutConstraint];
                return;
            }
        }
    }

    // 2. 创建原生约束
    self.layoutConstraint = [self createLayoutConstraint];

    // 3. 找到合适的安装视图
    MAS_VIEW *installView = [self.firstViewAttribute.view];
    if (self.secondViewAttribute.view) {
        installView = [installView mas_closestCommonSuperview:self.secondViewAttribute.view];
    }

    // 4. 添加约束
    [installView addConstraint:self.layoutConstraint];
}

// 创建NSLayoutConstraint
- (NSLayoutConstraint *)createLayoutConstraint {
    id firstItem = self.firstViewAttribute.item;
    id secondItem = self.secondViewAttribute.item;

    // 处理常量值
    if ([secondItem isKindOfClass:NSValue.class]) {
        secondItem = nil;
        self.secondViewAttribute = [[MASViewAttribute alloc]
                                   initWithView:nil
                                   item:nil
                                   layoutAttribute:NSLayoutAttributeNotAnAttribute];
    }

    return [NSLayoutConstraint constraintWithItem:firstItem
                                      attribute:self.firstViewAttribute.layoutAttribute
                                      relatedBy:self.layoutRelation
                                         toItem:secondItem
                                      attribute:self.secondViewAttribute.layoutAttribute
                                     multiplier:self.layoutMultiplier
                                       constant:self.layoutConstant];
}

// 查找最近公共父视图
- (instancetype)mas_closestCommonSuperview:(MAS_VIEW *)view {
    MAS_VIEW *closestCommonSuperview = nil;
    MAS_VIEW *secondViewSuperview = view;

    while (!closestCommonSuperview && secondViewSuperview) {
        MAS_VIEW *firstViewSuperview = self;
        while (!closestCommonSuperview && firstViewSuperview) {
            if (secondViewSuperview == firstViewSuperview) {
                closestCommonSuperview = secondViewSuperview;
            }
            firstViewSuperview = firstViewSuperview.superview;
        }
        secondViewSuperview = secondViewSuperview.superview;
    }

    return closestCommonSuperview;
}

复合约束安装 (MASCompositeConstraint)

flowchart TD A["install调用"] --> B["遍历children数组"] B --> C["每个child.install"] C --> D{"child是单约束?"} D -->|是| E["单约束安装流程"] D -->|否| F["递归复合约束"] E --> G["收集所有约束"] F --> G G --> H["全部完成"]

代码实现：

// MASCompositeConstraint.m
- (void)install {
    for (MASConstraint *child in self.children) {
        child.updateExisting = self.updateExisting;
        [child install];  // 递归调用
    }
}

- (void)uninstall {
    for (MASConstraint *child in self.children) {
        [child uninstall];
    }
}

// 链式操作转发
- (MASConstraint * (^)(id))equalTo {
    return ^id(id attribute) {
        for (MASConstraint *child in self.children) {
            [child equalTo:attribute];  // 转发给所有子约束
        }
        return self;
    };
}

- (MASConstraint * (^)(MASEdgeInsets))insets {
    return ^id(MASEdgeInsets insets) {
        for (MASConstraint *child in self.children) {
            if ([child isKindOfClass:MASViewConstraint.class]) {
                MASViewConstraint *viewConstraint = (MASViewConstraint *)child;
                NSLayoutAttribute attr = viewConstraint.firstViewAttribute.layoutAttribute;

                // 根据不同边设置不同偏移
                switch (attr) {
                    case NSLayoutAttributeTop:
                        [child offset:insets.top];
                        break;
                    case NSLayoutAttributeLeft:
                        [child offset:insets.left];
                        break;
                    case NSLayoutAttributeBottom:
                        [child offset:-insets.bottom];
                        break;
                    case NSLayoutAttributeRight:
                        [child offset:-insets.right];
                        break;
                    default:
                        break;
                }
            }
        }
        return self;
    };
}

更新匹配逻辑

// MASViewConstraint.m
- (BOOL)isEqualToConstraint:(MASViewConstraint *)constraint {
    // 比较第一个视图属性
    if (self.firstViewAttribute != constraint.firstViewAttribute) {
        return NO;
    }

    // 比较第二个视图属性
    if (self.secondViewAttribute != constraint.secondViewAttribute) {
        return NO;
    }

    // 比较布局属性
    if (self.firstViewAttribute.layoutAttribute != constraint.firstViewAttribute.layoutAttribute) {
        return NO;
    }

    return YES;
}

// 更新约束常量
- (void)setLayoutConstraint:(NSLayoutConstraint *)layoutConstraint {
    // 保持原有约束，只更新常量
    self.layoutConstraint = layoutConstraint;

    // 更新常量值
    layoutConstraint.constant = self.layoutConstant;

    // 更新优先级
    layoutConstraint.priority = self.layoutPriority;
}

卸载流程

flowchart TD A["uninstall调用"] --> B["获取layoutConstraint"] B --> C{"是否存在?"} C -->|否| D["直接返回"] C -->|是| E["从父视图移除"] E --> F["置空引用"] F --> G["完成"]

代码实现：

// MASViewConstraint.m
- (void)uninstall {
    // 1. 处理复合约束
    if ([self isKindOfClass:MASCompositeConstraint.class]) {
        [super uninstall];
        return;
    }

    // 2. 移除约束
    if ([self.layoutConstraint respondsToSelector:@selector(isActive)] && self.layoutConstraint.isActive) {
        [self.layoutConstraint setActive:NO];
    } else {
        [self.firstViewAttribute.view removeConstraint:self.layoutConstraint];
    }

    // 3. 清理引用
    self.layoutConstraint = nil;
    self.secondViewAttribute = nil;
}

// MASCompositeConstraint.m
- (void)uninstall {
    for (MASConstraint *child in self.children) {
        [child uninstall];
    }
}

🎓 本章要点总结

生命周期阶段

  1. 创建阶段：MASConstraintMaker初始化，设置标志位
  2. 配置阶段：用户Block执行，链式调用配置
  3. 安装阶段：遍历约束，创建NSLayoutConstraint
  4. 清理阶段：移除临时数组，返回结果

三种方法对比

方法标志位旧约束适用场景
makeConstraints无保留首次创建
updateConstraintsupdateExisting保留动态更新
remakeConstraintsremoveExisting移除完全重置

关键机制

  • 防御性复制：避免遍历时修改数组
  • 委托模式：处理约束替换和组合
  • 查找匹配：基于视图属性相等性
